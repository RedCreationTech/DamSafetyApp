# 沙漏弹性几何/幅值候选开发检查

默认`elastic_operator=legacy`逐字保留原残差路径。`gradient_raw_conjugate`只将弹性项替换为同A工况三帧U/ALLAE支持的`(0.005/16) G0 A M h hᵀ`，原Kold/ζ/HHT/历史阻尼保持。不存在自由η参数，材料、厚度及质量未改。

新模式直接相加`Kref*弹性历史+Clegacy*速度历史`，与旧算子加弹性差量代数等价，避免旧/新弹性约400:1时大数相减。框架JxW已提供面积，不重复乘A。默认分支不调用新几何函数。TRI3沿用原拒绝条件；实际坝输入只在QUAD4块挂沙漏。

`unit/src/HourglassEnergyReferenceTest.C`准备7项检查，涵盖绝对归一、几何不变性、实际AD矩阵/正反斜率、完整旧阻尼隔离、静力极限、接受历史的纯函数重放及非法几何；源码准备不等于C++已运行。纯函数拒绝重放不冒充全局FE回退。

本目录复用现有单自由度沙漏输入，准备静力及瞬态PetscJacobianTester与主动拒绝试步。运行后仍须将拒绝臂与显式相同接受时刻的无拒绝臂CSV比较，`RunApp`成功/出现拒绝标识本身不证明历史恢复一致。这些均是底层有界开发夹具，不是整坝或CDP正式验证。

需要集成仓库按AGENTS授权源码同步及锁定节点隔离构建后才能运行；本地没有MOOSE工具链。正式Gra/EQ及七冻结CDP回归只经LIMS。未通过开发检查不得提交整坝，不替换A/H50或B/H39基座。
